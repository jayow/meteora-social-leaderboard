# Pool Party teaser style frames: generation prompts (16:9, text-free plates)

Generate each prompt at 16:9 (1920x1080 or larger). Save the plates as raw/frame-01.png ... raw/frame-06.png,
then run `python3 composite.py`. It adds the real logo, the crisp Inter text and the UI cards, and writes frame-0N.png + contact-sheet.jpg.
If a plate's composition differs, nudge the anchor fractions in LAYOUT in composite.py and rerun `python3 composite.py N`.

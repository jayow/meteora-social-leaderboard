# Pool Party teaser assets

Style frames for a Pool Party teaser in a deadpan pitchman x surreal AI style.

## Layout

- `frames/` — composited teaser frames with logo and copy
- `clean/` — clean plates for re-compositing
- `prompts.md` — generation prompts and notes
- `contact-sheet.jpg` — visual overview of the set

## Intended use

Animate the frames via image-to-video. Use the clean plates when re-compositing
or adapting the visuals for new edits.
